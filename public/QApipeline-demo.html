# PRD (Business Level) — KODA
### Buy Now, Pay Later · Installment Payment Platform

## 1. Executive Summary
KODA enables 4–24 installment payments with dynamic
fee rates. Zero-interest for 4-term plans.

## 2. Problem Statement
SEA consumers lack flexible credit for $300+ purchases.

## 3. Target Users
• Buyers: 18-35, mobile-first, limited credit access
• Merchants: SME e-commerce, instant settlement needed

## 4. Business Rules
Fee rates: 4:0% / 6:3.98% / 8:6.22% ... 24:23.38%
Commission: 2.5% per order (merchant payout = 97.5%)
Lock: Overdue accounts → blocked at checkout

## 5. Success Metrics (ROI)
GMV, approval rate, 30-day default rate (<2%)

Context Strategy E. Context Strategy — Agentic QA Pipeline

Context Management: Keep Decisions, Drop Process

On large projects (27 stories / 6 sprints), unmanaged context fills the window before the report is written. This strategy prevents that.

KEEP in full
Decisions — ACs, TC-IDs, defect IDs, verdicts, skill overrides.
These are referenced by every later step. Never compress.
COMPRESS
Evidence — observation logs, raw Playwright output, run logs.
Compress to summary table + bug list only.
DROP
Process — skill instructions, boilerplate, intermediate reasoning.
These live in skill files. Never carry in context.
