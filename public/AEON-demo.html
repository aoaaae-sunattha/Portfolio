What is AEON Lite

Not a chatbot.
A learning system.

AEON Lite uses Hermes AI skills, Node.js determinism, Obsidian memory, and Telegram delivery to create, score, and improve crypto signals over time.

🤖
Agent Reasoning
Hermes skills analyze macro context, apply past lessons, and produce LONG / SHORT / HOLD signals per coin.
Hermes AI

Hermes Skills

Specialized agents,
not one chatbot.

Each Hermes skill has one focused job. This prevents hallucination drift and makes the system auditable.

aeon-risk-gate
Risk filter · runs first
Checks ATR and data completeness before any trade decision. Blocks the symbol if volatility is unsafe. Protects the trader from bad market conditions.
→ { "status": "PASS" | "BLOCK", "block_reason": "..." }
Active in cycle
aeon-market-researcher
Macro analyst · runs once
Researches DXY, gold, oil, US10Y yield, ETF flows, and geopolitical risk before any forecasts are made. Provides the macro lens for all three coins.
→ { "macro": { "dxy": ..., "news_summary": [...] } }
Active in cycle
aeon-trader
Forecast agent · per symbol
Receives technicals + past lessons and returns a structured LONG/SHORT/HOLD decision. Past lessons are injected as binding warnings.
→ { "action": "LONG", "confidence": 72, "stop_loss_zone": ... }
Active in cycle
aeon-self-evaluator
QA auditor · after losses
Reviews a completed LOSS or high-confidence PARTIAL and writes exactly one reusable lesson. Never changes numeric scores — those are set by Node.js.
→ LESSON: Do not LONG when DXY > 106...
Active in cycle
aeon-sentiment-agent
Sentiment analyst · standalone
Scores fear/greed index, social mood, whale activity, and funding direction. Available on-demand for deeper market context queries.
→ { "sentiment": { "fear_greed_score": 62, "social_mood": "bullish" } }
Standalone
aeon-morning-brief
User briefing · on request
Reads yesterday's vault files and explains results in plain, non-technical language. Designed for quick phone reading. Answers "what happened?" and "what do I do today?"
→ Plain-language Telegram-ready summary
